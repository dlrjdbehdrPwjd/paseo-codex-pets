# 파세오 바탕화면 펫 베타

**이 베타는 Windows x64·Codex 26.1027.6604만 지원합니다. 현재 Codex 26.1029.7803은 지원하지 않으며 준비 단계에서 중단합니다.** 다른 버전 지원이 필요하면 이 패키지를 설치하지 마세요. 원본 UI를 로컬 설치본에서 준비하므로 Codex를 설치하지 않은 PC에서도 실행되지 않습니다.

Node.js24 이상·npm과 Paseo가 필요합니다. 다음 명령으로 베타 버전을 지정해 설치합니다.

```powershell
paseo plugin add npm:paseo-codex-pets@next
```

설치 과정에서 고정된 npm 의존성을 준비하고 자신의 Codex 설치본을 확인·추출한 다음 Electron40.10.6을 내려받아 펫 실행본을 만듭니다. Codex 원본 코드·자산은 npm 패키지에 포함하지 않습니다. 준비에 인터넷·수 GB 여유 공간과 몇 분이 필요할 수 있습니다. 파세오 플러그인 설치는 이 신뢰 코드와 준비 명령을 사용자 권한으로 실행합니다. 플러그인 전역 설정은 이 패키지가 켜지 않습니다.

일반 npm 설치만으로 파세오에 등록되지는 않습니다. 지원 버전 확인만 하거나 폴더를 직접 준비할 때의 절차·파일 접근·해제는 아래 설명을 참고하세요. 공식 플러그인 목록 등록은 별도이며 이 베타의 npm 게시가 공식 심사 통과를 의미하지 않습니다.

# 파세오 바탕화면 펫

파세오 대화 상태와 연결되는 Windows 바탕화면 펫입니다. 대화·메시지·승인·받아쓰기·펫 선택을 연결하며 커뮤니티 펫을 설치할 수 있습니다. OpenAI나 Paseo의 공식 플러그인이 아닙니다.

## 준비 조건

- Windows x64, Node.js 24 이상과 npm, Paseo 0.14.0에서 검증했습니다. 다른 운영체제는 지원하지 않습니다.
- 자신의 PC에 Codex 26.1027.6604 설치본이 있어야 합니다. 준비 과정에서 SHA-256을 확인하고 다르면 중단합니다. 최신 Codex 전체 버전 호환을 의미하지 않습니다. 지원하지 않는 버전의 원본을 이 패키지에 대신 동봉하거나 타인에게 요청하지 마세요.
- Codex 원본 코드·이미지·폰트·Electron 실행 파일을 이 공유물에 포함하지 않습니다. Codex는 로컬 설치본에서 읽고 Electron 40.10.6은 준비 중 공식 Electron 배포 경로에서 내려받습니다. npm 의존성·전이 의존성은 동봉 lock으로 고정합니다.
- 파세오 서버 플러그인은 사용자 권한으로 실행됩니다. 로컬 파세오 인증 파일·대화 상태·사용자가 첨부한 파일을 읽습니다. 메시지·첨부·오디오는 기존 파세오와 설정된 제공자로 전송됩니다. 커뮤니티 펫 설치 요청 시 codex-pets.net에 접속합니다.

## 공유 ZIP 설치

ZIP을 원하는 **영구 폴더**에 풀고 해당 폴더에서 PowerShell로 실행하세요. 준비된 폴더를 나중에 옮기면 다시 준비해야 합니다.

```powershell
npm ci --ignore-scripts
node .\tools\prepare.cjs
paseo plugin install "$((Get-Location).Path)"
```

첫 두 명령은 Codex 파일을 로컬로 추출·분석하고 Electron을 내려받아 펫 실행본을 만듭니다. 설치 마지막 명령 전까지 현재 파세오 플러그인은 변경하지 않습니다. 임의의 원본 앱 초기화나 Codex 실행은 하지 않습니다. 준비 중에는 인터넷·수 GB의 여유 디스크 공간이 필요하며 파일 분석에 몇 분 걸릴 수 있습니다. 실패 시 파세오에 설치하지 말고 오류를 확인하세요. 같은 ID의 기존 펫이 있으면 설치가 그 플러그인을 교체할 수 있으므로 기존 경로를 먼저 기록하세요. 업데이트는 새 폴더에서 준비하고 실행 중인 설치 폴더를 직접 덮어쓰지 마세요.

자동으로 Codex를 찾지 못하면 자신의 설치 경로를 지정할 수 있습니다. 지원 여부만 확인하려면 다음처럼 실행합니다.

```powershell
$env:PASEO_CODEX_ASAR = '자신의 Codex 설치 폴더\app\resources\app.asar'
node .\tools\prepare.cjs --check
```

플러그인을 아직 전역으로 허용하지 않았다면 파세오 설정의 플러그인 항목에서 활성화하세요. 이 설치 도구는 전역 설정을 임의로 켜지 않습니다. 공개 주소와 게시 상태는 해당 배포 버전의 안내를 기준으로 확인하세요. 이 절차는 폴더·ZIP을 직접 준비할 때 사용합니다.

## 사용

명령창에서 ‘펫 설정’·‘펫 보이기 / 숨기기’·‘펫 다시 시작’을 사용합니다. 펫 입력창에 `npx codex-pets add guga`를 보내면 다운로드 후 선택합니다. 터미널에서 같은 명령으로 새 펫을 설치해도 감지합니다. 설치 폴더는 `CODEX_HOME/pets`, 기본은 사용자 홈의 `.codex/pets`이며 Codex와 공유합니다. 펫 선택·크기는 별도의 `PaseoCodexPet` 사용자 데이터 폴더에 저장합니다.

새 대화는 최근 활성 파세오 대화의 제공자·모델·작업공간을 사용합니다. 활성 대화가 없으면 먼저 파세오에서 대화를 하나 준비하세요. 다른 PC의 대화 ID·경로·인증 정보를 공유물에 포함하지 않습니다.

## 해제와 한계

```powershell
paseo plugin disable paseo-codex-pets
paseo plugin remove paseo-codex-pets
```

이 명령은 다른 플러그인을 끄지 않습니다. 원본 Codex 설치와 다운로드한 펫·개인 설정은 삭제하지 않습니다. 공유한 준비 전 ZIP만 재배포하고, 준비 후 생긴 `research/`·`artifacts/`·`node_modules/`·로컬 설정은 다시 묶지 마세요.

실제 guga 설치·선택·재시작 복원은 확인했습니다. 실제 승인·물리 마이크·양방향 음성·파세오 전체 종료와 모든 갤러리 펫 호환은 확인되지 않았습니다. 원본 UI 의존성을 유지하므로 Codex 업데이트마다 별도 지원 검증이 필요합니다. 공식 플러그인 목록 등록·심사는 아직 하지 않았습니다.
